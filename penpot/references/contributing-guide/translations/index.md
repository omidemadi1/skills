# Translations

Thank you for interest in contribute translating Penpot. Here you will find ways to do it.

## How to become a Penpot translator

We are using [Weblate](https://hosted.weblate.org/projects/penpot/frontend/) as translation platform, so the first thing you need to be a Penpot translator is to have a Weblate account (you can [register here](https://hosted.weblate.org/accounts/register/)).

To start translating at Penpot:

1. Open a [github issue](https://github.com/penpot/penpot/issues) giving details about the language you want to translate (language), the type of translation (new language, new translation or change an existing translation) and your Weblate user.
2. If everything is correct we will get back to you providing you permissions to the actions needed.
3. You also might want to take a look at the guide for [Translating using Weblate](https://docs.weblate.org/en/latest/user/translating.html).

## Add a new language

To add a language that is still not among the Penpot language options:

1. Go to the [languages list](https://hosted.weblate.org/projects/penpot/frontend/).
2. Press the "Start new translation" button.
3. Choose the language you want to translate to.
4. Press the "Start new translation" button at the start new translation page.
5. Start translating strings for the new language :)

## Add a new translation

To add a new translation (a string with a lacking translation for a certain language) follow the next steps:

1. Go to the [languages list](https://hosted.weblate.org/projects/penpot/frontend/).
2. Click the edit button (pencil icon) close to the name of the language where you want to add the missing translation or translations.
3. Find and select the translation/s to complete.
4. Complete the translation in the required input field.
5. Press the "Save· button.
6. Repeat the action with as many translation strings you can / you want ;)

Saved new translations will automatically get the status "waiting for review". Our team will periodically check strings waiting for review and, if considered correct, will approve them.

## Change an approved translation

To edit an already approved translation string follow the next steps:

1. Go to the [languages list](https://hosted.weblate.org/projects/penpot/frontend/).
2. Click the name of the language where is the translation you want to change.
3. Click the Browse button.
4. Find and select the translation/s to complete.
5. Change the translation in the input field.
6. Press the "Save" button if you have permissions.
7. If you don't have permissions to Save you can still press "Suggest" to make a suggestion.

Saved editions will get the status "Waiting for review". Suggestions will get the status "Approved strings with suggestions". Our team will periodically check strings waiting for review and, if considered correct, will approve them.
