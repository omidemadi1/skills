# Libraries & templates

There are published Penpot files ready to use made by community members and Penpot core team members.

- Here you can find the complete list of [available Libraries & Templates](https://penpot.app/libraries-templates).
- Are you willing to contribute sharing a Penpot file with the Penpot community? Here's a [how you can do it](https://penpot.app/how-to-contribute).
- If you are in doubt about how to use one of these files, here you can [watch a video explanation](https://penpot.app/libraries-templates#how-to-use).
