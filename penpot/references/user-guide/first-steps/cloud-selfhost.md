# Cloud or Self-host

You can start using Penpot right in your browser or installing it in a server of your own.

## In your browser

To use Penpot online point your browser to [design.penpot.app](https://design.penpot.app) and start designing. Use the latest Google Chrome or Mozilla Firefox for the best experience. We also provide specific support to WebKit (Safari / Epiphany).

You can also go to [penpot.app](https://penpot.app) if you want to read more about Penpot and our new releases. There, click on the Signup button. You will be asked to create an account. We only ask for an email. There are some authentication providers available too.

## On your own server

Currently, private Penpot instances only require basic Docker knowledge.

You can run your own Penpot server following the instructions at the [Technical Guide](/technical-guide/getting-started)
