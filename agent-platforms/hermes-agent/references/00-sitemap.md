`website/docs/`. The bundled reference files in this skill (01-18) already
contain the most commonly needed pages in full. For anything else, fetch the
raw markdown directly - no HTML, no boilerplate:

```bash
curl -s "https://raw.githubusercontent.com/NousResearch/hermes-agent/main/website/docs/<path>"
```

(`raw.githubusercontent.com` and `github.com` are reachable from the bash
tool.) Or use `web_fetch` on `https://hermes-agent.nousresearch.com/docs/<path-without-.md>`
for the rendered version.

For real-world community setups, workflows, and worked examples (not official
docs), search https://www.hermesbible.com/flows or web_search site:hermesbible.com.
