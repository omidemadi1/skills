# Weather Dashboard App

A React + TypeScript web application that displays weather data from OpenWeatherMap API.

## Features

- Dashboard with interactive charts showing temperature, humidity, wind speed
- User authentication with JWT
- Location search and favorites
- Responsive design for mobile and desktop

## Tech Stack

- Frontend: React, TypeScript, Chart.js
- Backend: Node.js, Express
- Database: PostgreSQL
- Authentication: JWT, bcrypt
- Deployment: Docker, Docker Compose
- CI/CD: GitHub Actions

## Architecture

- Frontend SPA with component-based architecture
- RESTful API backend
- JWT-based authentication
- Environment-based configuration

## Special Requirements

- Must support deployment to AWS ECS
- Need comprehensive testing with Jest and React Testing Library
- Require ESLint and Prettier for code formatting
